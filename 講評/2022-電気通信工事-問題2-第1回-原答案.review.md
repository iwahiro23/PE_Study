# 令和4年度 問題2 第1回講評

- 対象：[原答案](../答案/2022-電気通信工事-問題2-第1回-原答案.md)
- 練習用評価：**70/100点前後**。公式採点ではない。

| 項目 | 評価 | 直すポイント |
| --- | --- | --- |
| 機器の据付け | 一部可 | ボルト・ナットの緩み確認は妥当。アンカーボルトを所定の締付けで確実に固定する等、実施方法まで具体化する。 |
| ケーブルラックの敷設 | 可 | ラック相互の電気的接続は妥当。接続部のボルトや導通確認まで書くと明確。 |
| カメラ | 一部可 | 名称は正しい。「固定された画角」という限定は図記号から読み取れない。監視映像の撮影・伝送・記録を書く。 |
| カードリーダー | 可 | 名称とカードによる電気錠の施解錠という機能は妥当。 |
| 設問3 ア | 誤 | 磁束密度ではなく**インダクタンス**。 |
| 設問3 イ | 部分点の可能性 | 「前後進」より**進行方向**と明記する。 |

参考：[国土交通省のケーブルラック施工仕様](https://www.mlit.go.jp/tec/it/denki/gijyutukijyun/R0703kouji_kaitei.pdf)、[民間の解答試案](https://www.southernsoft.co.jp/1dentsu2022-1.pdf)。
