# 2025年度 問題2の講評

- 対象は1級電気通信工事施工管理技術検定 第二次検定 問題2。採点日 2026年11月24日。
- [全国建設研修センターの公式問題PDF](https://www.jctc.jp/wjctcp/wp-content/uploads/2025/12/20251208e_mondai.pdf)の冊子3～4ページを参照。
- 練習用の暫定得点は **55／60点**。設問Bの40点分は図記号の照合が必要なため保留。確信度はAが中、Cが高。
- 練習用配点はAの記述2件とBの名称・機能の組2件を各20点、Cの空欄2件を各10点。名称と機能を一組として評価し、穴埋めは正誤で判定する。

## 設問別チェックと減点理由

| 項目 | 得点 | 根拠 |
| --- | ---: | --- |
| A 金属拡張アンカー | 18／20 | 対応8、技術5、具体性3、表現2。「テープでマーキング」「粉を吸引」で穿孔深さと孔内清掃を具体化。清掃は使用製品の施工要領に従うこと、打込み後の完了確認も書くと、施工管理の手順が明確になる。 |
| A 工具の取扱い | 17／20 | 対応8、技術4、具体性3、表現2。落下による負傷を防ぐ目的とワイヤーの使用を明示。「バケットの手すり」が使えるかは機種の取扱説明書で要確認。工具の質量に合う器具と、取付け箇所を確認する手順があると具体的。 |
| B あ・い | 保留／40 | 名称と機能を両方記載。「熱式火災検知器」「押しボタン型通報装置」が図のJIS記号に対応するか要確認。記号の照合後に名称と機能を採点する。 |
| C 空欄2件 | 20／20 | カスケード、スタックともに正答。 |

## 良い点

Aは4つの選択肢から2つを選び、手順と防ぎたい事象を説明できた。Cは両方の接続方式を区別できている。

## 優先して直す3点

1. Bは系統図の該当記号と接続先を確認し、JISの名称と機能を照合する。
2. 工具の落下防止器具を固定できる箇所と、器具の使用条件を確認する。
3. アンカーは穿孔と清掃に加え、使用製品に応じた打込み完了の確認を書く。

## 修正文の一例

- アンカー。施工要領で指定された穿孔深さを確認し、ドリル刃に付けた目印で穿孔深さを管理する。穿孔後は施工要領に従って孔内の切粉を除去し、打込み後は所定の方法で施工完了を確認する。
- 工具。高所作業車で工具を使用するときは、工具の質量に適合する落下防止器具を使用し、バケット側は取扱説明書で使用できることを確認した箇所に取り付ける。

## 要確認の事実と出典

- 設問Bの図記号の形と接続先。参照 [JIS C 0303の掲載資料](https://kikakurui.com/c0/C0303-2000-01.html)
- アンカーごとの清掃方法と打込み完了の判定方法。参照 [サンコーテクノの施工手順](https://sanko-techno.co.jp/products/metal/anchor09/)
- ワイヤーの取付け箇所は高所作業車の機種別説明書で確認。参照 [3Mの工具落下防止器具](https://www.3mcompany.jp/3M/ja_JP/fall-protection/products/tools/)
- Cの照合資料 [接続方式の解説](https://note.com/anzen_ai_jp/n/na8b31e09333d)

## 次回の練習

Bの系統図にある「あ」「い」の記号と接続先を確認し、器具ごとに「名称」「何を検知・操作するか」「どこに何を伝えるか」を一行で書く。
